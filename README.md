# Study Space — Feature Set

A GitHub Pages-ready visual research report created from the provided Study Space Feature Set document.

## Files
- `index.html` — report structure
- `style.css` — visual design
- `script.js` — navigation and image viewer
- `assets/study-space-source.png` — source visual extracted from the document

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save. GitHub will provide the public Pages URL.
